# 차림(CHARIM) 브랜딩 가이드

> **오늘의 수업을 차리다.**

## 1. 브랜드 개요

### 브랜드명
- 한글: **차림**
- 영문: **CHARIM**

### 핵심 슬로건
**오늘의 수업을 차리다.**

### 브랜드 핵심 개념
'차림'은 '차리다'의 명사형으로, 교사가 매일 수업을 준비하고 정돈하는 과정을 의미합니다.

차림은 다음과 같은 교사의 일상을 한곳에서 간단하고 체계적으로 준비할 수 있도록 돕는 **교사용 수업 관리 도구**를 지향합니다.

- 시간표 확인
- 수업 자료 준비
- 수업 내용 확인
- 수업 기록
- 학급별 수업 관리

### 브랜드 키워드
- 정돈
- 준비
- 수업
- 하루
- 기록
- 간결함
- 신뢰감

---

## 2. 브랜드 포지셔닝

차림은 학생을 위한 놀이·창작 중심 서비스보다는 **교사가 매일 사용하는 실용적인 수업 도구**에 초점을 둡니다.

### 브랜드가 전달해야 할 인상
- 깔끔한
- 정돈된
- 빠르게 사용할 수 있는
- 신뢰할 수 있는
- 부담 없는
- 현대적인
- 교육 현장에 자연스럽게 어울리는

### 피해야 할 인상
- 지나치게 장난스러운 느낌
- 캐릭터 중심의 디자인
- 지나치게 화려한 색상
- 오래된 학교 행정 시스템 같은 느낌
- 복잡하고 무거운 기업용 관리 시스템 느낌

# 3. 로고

## 3-1. 메인 로고

기존에 선정한 **3안 심볼**을 기본 로고로 사용합니다.

### 로고 구성
**ㅊ + ㄹ을 추상화한 심볼 + 차림 + CHARIM**

심볼은 한글 자음 `ㅊ`과 `ㄹ`의 형태를 직접적으로 드러내면서도 단순한 자음 조합이 아니라 하나의 독립적인 브랜드 심볼처럼 보이도록 구성합니다.

### 로고의 의미

- `ㅊ` : 차림의 시작
- `ㄹ` : 차림의 흐름
- 두 형태가 연결되며 **수업을 정돈하고 준비하는 과정**을 표현

단, 로고의 의미를 지나치게 설명하기보다는 시각적으로 간결하고 기억하기 쉬운 심볼로 사용하는 것을 우선합니다.

# 6. 색상 사용 방향

전체적인 색상 비율은 **화이트/밝은 회색을 넓게 사용하고 블루를 핵심 포인트로 사용하는 방식**을 권장합니다.

예시:

- 배경: 밝은 회색
- 카드: 흰색
- 제목/본문: 짙은 네이비
- 주요 버튼: Primary Blue
- 선택 상태: Primary Blue
- 보조 정보: Secondary Blue
- 성공/주의/오류: 상태 색상

노란색이나 크림색을 브랜드 메인 색상으로 사용하지 않습니다.

# 12. 학생 화면

학생 화면은 교사 화면보다 여백을 넉넉하게 사용합니다.

### 특징
- 간단한 상단 네비게이션
- 큰 제목
- 카드 중심 구조
- 시각적으로 이해하기 쉬운 메뉴
- 불필요한 관리 정보 제거

### 주요 메뉴
- 오늘의 수업
- 수업 내용
- 자료
- 시간표

학생에게는 교사 관리 기능이나 기록 기능을 노출하지 않습니다.

---

# 13. 교사 화면과 학생 화면의 관계

두 화면은 완전히 다른 디자인으로 만들기보다는 **같은 브랜드 디자인 시스템 안에서 밀도만 다르게 구성**합니다.

### 공유 요소
- 로고
- 색상
- 폰트
- 아이콘 스타일
- 버튼 스타일
- 카드 스타일
- 기본 컴포넌트

### 차이
- 교사: 정보 밀도 높음
- 학생: 여백 넓음
- 교사: 관리/기록 중심
- 학생: 확인/학습 중심

# 16. 브랜드 스토리

> 교사는 매일 수업을 차립니다.
>
> 시간표를 확인하고, 자료를 준비하고, 학생을 만나고, 수업을 기록합니다.
>
> **차림은 교사의 하루를 한곳에 모아 수업을 간단하고 정돈된 방식으로 준비할 수 있도록 돕습니다.**
>
> 그래서 차림은 단순한 관리 시스템이 아니라, 교사가 매일 꺼내 쓰는 **수업 도구**입니다.

# 17. 디자인 원칙

차림의 디자인은 다음 네 가지 원칙을 유지합니다.

### 01. 정돈
정보가 많아도 한눈에 구조가 보여야 합니다.

### 02. 준비
오늘의 수업을 시작하기 전에 필요한 정보를 빠르게 확인할 수 있어야 합니다.

### 03. 간결함
기능을 많이 보여주기보다 지금 필요한 기능을 우선적으로 보여줍니다.

### 04. 신뢰감
학교 현장에서 매일 사용해도 부담스럽지 않은 안정적인 디자인을 유지합니다.

# 18. CHICODE와의 브랜드 차별화

차림은 기존 CHICODE와 명확하게 다른 브랜드로 운영합니다.

| 구분 | CHICODE | 차림 |
|---|---|---|
| 핵심 대상 | 학생 중심 | 교사 중심 |
| 핵심 경험 | 배우고 만들기 | 준비하고 확인하기 |
| 분위기 | 즐겁고 친근함 | 차분하고 정돈됨 |
| 색상 | 노랑/크림 계열 | 블루/네이비/화이트 |
| 그래픽 | 치즈 캐릭터 | 미니멀 심볼 |
| 폰트 | 학생 친화적 디스플레이 | Pretendard 중심 |
| 핵심 메시지 | 재미에 코드를 더하다 | 오늘의 수업을 차리다 |

차림에서는 CHICODE의 치즈 캐릭터, 노란색/크림색 중심의 색상, 장난스러운 그래픽 스타일을 사용하지 않습니다.

# 20. 다른 AI에게 전달할 때의 핵심 지시

다음 원칙을 반드시 유지합니다.

> **차림의 핵심은 '예쁜 교육 서비스'가 아니라 '교사가 매일 사용하는 정돈된 수업 도구'이다.**
>
> 기존에 선정한 `ㅊㄹ` 심볼의 형태와 브랜드 방향을 임의로 크게 변경하지 않는다.
>
> 디자인은 블루/네이비/화이트 기반의 미니멀한 방향을 유지하고, Pretendard를 기본 서체로 사용한다.
>
> 교사 화면은 정보 밀도가 높지만 빠르게 파악할 수 있어야 하며, 학생 화면은 같은 디자인 시스템을 유지하면서 여백을 넉넉하게 구성한다.
>
> 캐릭터 중심의 디자인이나 노란색/크림색 중심의 CHICODE 스타일을 차림에 가져오지 않는다.
>
> 모든 디자인 요소는 **정돈 · 준비 · 기록 · 간결함 · 신뢰감**이라는 브랜드 키워드와 연결되어야 한다.
