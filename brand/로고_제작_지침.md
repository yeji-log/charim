# 차림 CHARIM — 로고 SVG 제작 지침

## 1. 제작 목표

차림의 공식 로고는 기존에 선정한 **3안 `ㅊㄹ` 심볼**을 중심으로 제작한다.

핵심 방향은 다음과 같다.

- `ㅊ`과 `ㄹ`의 특징이 자연스럽게 느껴지는 추상 심볼
- 단순한 자음 조합이 아니라 독립적인 브랜드 심볼로 인식
- 교사용 수업 도구라는 브랜드의 정돈·신뢰·간결함 표현
- 웹, 파비콘, 모바일 앱 아이콘, 인쇄물 등 다양한 크기에서 사용 가능
- 불필요한 장식이나 캐릭터 요소를 사용하지 않음

---

# 2. 공식 로고 구성

## Primary Logo

다음 순서로 구성한다.

`[ㅊㄹ 심볼] + 차림 + CHARIM`

예시 구조:

```text
[심볼]  차림
        C H A R I M
```

슬로건은 공식 로고 자체에 항상 포함하지 않는다.

필요한 경우 별도의 브랜드 소개 영역에서 사용한다.

> 오늘의 수업을 차리다.

---

# 3. 심볼 디자인

## 핵심 형태

기존에 선정한 3안의 심볼을 기준으로 한다.

심볼은 다음 특징을 유지한다.

- 위쪽에 작은 원형 요소
- 수평적인 중심 획
- 하단의 흐름을 나타내는 곡선/수평 형태
- `ㅊ`과 `ㄹ`을 연상시키는 구조
- 좌우 또는 상하 요소가 하나의 흐름으로 연결된 인상
- 둥글고 부드러운 모서리
- 지나치게 기하학적이거나 딱딱하지 않은 형태

**중요:** 기존 심볼을 다른 모양의 `ㅊㄹ` 조합으로 다시 디자인하지 않는다.

---

# 4. 심볼의 시각적 성격

다음 세 가지 느낌을 동시에 가져야 한다.

### 정돈

수평선과 일정한 간격을 활용하여 정보가 정리된 느낌을 준다.

### 흐름

곡선 또는 연결된 형태를 통해 수업이 준비되고 진행되는 흐름을 표현한다.

### 간결함

작은 크기에서도 형태가 유지되도록 세부 요소를 최소화한다.

# 6. 그라데이션 사용

기본 로고는 **단색 또는 최소한의 2색 조합**을 우선한다.

그라데이션은 필수 요소가 아니다.

사용한다면 다음 원칙을 따른다.

- Primary Blue → Secondary Blue 계열
- 과도한 광택 효과 금지
- 3D 효과 금지
- 네온 효과 금지
- 그림자 효과 금지

브랜드 로고 자체는 Flat Design을 우선한다.

# 9. SVG 제작 방식

## 기본 원칙

SVG는 실제 서비스에 바로 사용할 수 있도록 제작한다.

### 필수 조건

- 벡터 Path 기반
- 외부 이미지 참조 금지
- Base64 이미지 삽입 금지
- 불필요한 메타데이터 제거
- 불필요한 `<g>` 중첩 최소화
- CSS 의존 최소화
- 색상은 명시적인 Fill 사용
- Responsive ViewBox 사용

---

# 10. SVG ViewBox

심볼 단독 SVG는 정사각형 ViewBox를 권장한다.

예:

```xml
viewBox="0 0 512 512"
```

가로형 로고는 별도의 ViewBox를 사용한다.

예:

```xml
viewBox="0 0 1000 320"
```

단, 실제 Path 제작 시 로고의 여백을 고려하여 ViewBox를 설정한다.

# 12. 파비콘용 SVG

파비콘은 심볼 단독 버전을 사용한다.

파일:

```text
favicon.svg
```

권장 구조:

```text
Primary Blue 심볼
+
투명 또는 흰색 배경
```

16×16에서도 형태가 무너지지 않아야 한다.

---

# 13. 앱 아이콘

앱 아이콘은 심볼을 둥근 사각형 안에 배치한다.

### 기본

- 배경: `#315C8C`
- 심볼: `#FFFFFF`
- 둥근 모서리
- 심볼 주변 충분한 여백

텍스트 `차림`은 넣지 않는다.

권장 제작 크기:

```text
512 × 512
1024 × 1024
```

---

# 14. 최소 사용 크기

## 심볼

권장 최소 크기:

```text
16px
```

단, 16px에서는 세부 요소가 명확하게 보이지 않을 수 있으므로 실제 브라우저 탭에서는 16px 전용 최적화 버전을 사용할 수 있다.

## 가로형 로고

권장 최소 높이:

```text
24px 이상
```

브랜드 식별이 필요한 경우:

```text
32px 이상
```

---

# 15. 보호 공간(Clear Space)

로고 주변에는 충분한 여백을 둔다.

기준 단위는 심볼 상단의 작은 원형 요소의 직경을 `X`로 정의한다.

최소 보호 공간:

```text
상/하/좌/우 = 1X
```

가능하면 웹사이트 헤더에서는 1.5X 이상의 여백을 사용한다.

# 21. 최종 목표

차림의 로고는 단순히 '교사 서비스'를 나타내는 로고가 아니라,

**정돈 → 준비 → 수업 → 기록**

이라는 교사의 하루 흐름을 상징하는 브랜드 아이덴티티가 되어야 합니다.

가장 중요한 것은 **기존에 선택한 3안 심볼의 형태를 유지하면서 실제 서비스에서 사용할 수 있는 SVG 시스템으로 정교화하는 것**입니다.
